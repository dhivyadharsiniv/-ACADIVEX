# EduManage Frontend

An ultra-modern, colorful, interactive web interface for the EduManage Student Management System.

## Highlights & Features

- 🌈 **Vibrant & Colorful Visual Design**: Aurora glow gradients, glassmorphism, responsive cards, micro-interactions, dark/light theme toggle.
- 👑 **Multi-Role Experience**: Instant 1-click toggle between **Administrator**, **Teacher**, and **Student** personas with adapted KPI cards, greeting, timetable, and access permissions.
- 🎓 **Interactive Student Records**: Real-time search, multi-filter by Grade and Tuition status, "Enroll New Student" modal with form validation, and instant CSV data export.
- 👨‍🏫 **Faculty & Teacher Directory**: Teacher profiles with department tags, experience, rating badges, and class assignments.
- 📅 **Smart Attendance System**: Class selector, date picker, bulk "Mark All Present" / "Mark All Absent", 1-click student status switches, and real-time attendance compliance recalculations.
- 📝 **Examinations & Verifiable Report Cards**: Upcoming exam schedules, and a **Printable Official School Report Card Modal** with institution crest, course grades table, GPA calculation (4.0 scale), academic standing badge, and signature fields.
- 💳 **Fee Ledger & Payment Gateway**: Financial overview, invoice records, interactive online payment modal (card/UPI simulator with celebration confetti), and **Printable Official Fee Receipt** with invoice reference, timestamp, and verification badge.
- ⚡ **Zero-Dependency Instant Web Launch**: Double-click `index.html` to open directly in any web browser with 100% interactive features, plus optional connection to the Node.js backend (`http://localhost:5000/api`).

## Running the Webpage

### Option 1: Instant Direct Launch (Recommended)
Simply double-click or open `frontend/index.html` in your browser (Google Chrome, Microsoft Edge, Firefox, Brave, Safari).

### Option 2: Run with Next.js
```bash
cd frontend
npm install
npm run dev
```
Open `http://localhost:3000` in your browser.
